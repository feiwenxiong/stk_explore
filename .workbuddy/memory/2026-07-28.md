# 2026-07-28

## Bug 修复
- **ggui.py L369**: `ttk.Button` 不支持 `size="sm"` 参数，导致创建分时图标签页时报 `unknown option "-size"` 错误。移除该参数后修复。

## RemoteDisconnected 重试增强
- **akshare_patch.py** `_mount_retry_adapter`: 重试 total 从 2→3，backoff_factor 从 0.3→0.5，连接重试更充分
- **ggui.py** `safe_akshare_call`: 最大重试从 3→5，初始等待从 0.1~0.5s 提升到 0.5~1.5s，各次等待从 2^attempt 开始指数增长
- **fenshitu_tab.py** `_akshare_retry`: 同样增强到 max_retries=5，首次等待 0.5~1s

## 分时图板块数据 API 修复
- **关键发现**: 东财 push2his API 的板块分时数据接口 (`secid=90.XXXX`) 不接受 "BK" 前缀
- **修复**: `fenshitu_tab.py` `get_minutely_data()` 中 `bankuai=True` 时，将板块代码的 "BK" 前缀去掉（如 `BK0507` → `0507`）
- **验证**: 修复后板块分时返回 87 条数据 ✅，完整流程（指数+6板块+板块内个股）47.7秒跑通

## 涨停池日期/间隔变量 GC 修复
- **bug**: `create_limit_up_tab()` 中 `date_var` 和 `duration_var` 是局部变量，方法返回后可能被 Python GC 回收，导致 Entry 显示空白、启动时读到空字符串
- **修复**: 改为 `self.date_var` / `self.duration_var` 实例属性，确保 Tcl 变量存活
