### 问题4：akshare 补丁递归包裹（严重影响性能）
- `patch_akshare_direct()` 被调用了 5-6 次（akshare_patch.py 模块自动执行 + ggui.py 显式调用 + zhangting.py 再次调用 + hot_stock.py 再次调用）
- 每次调用把 `requests.get` 再包一层 wrapper，形成 6 层嵌套函数调用
- 每层 wrapper 都加 `sleep(0.1-0.5)`，导致每个 HTTP 请求额外延迟 0.6-3 秒
- 延迟叠加可能触发东方财富服务器超时断开连接

### 修复方案
- `instock/lib/akshare_patch.py`：添加 `_session_patched` / `_direct_patched` 标志，确保 patch 只应用一次（幂等）
- 去掉了内部 patch 函数中的 sleep 延迟（由外层 `safe_akshare_call` 统一控制）
- 为东方财富/同花顺域名自动添加 `Referer: https://data.eastmoney.com/`
- 设置 15 秒超时、添加浏览器标准头部（Accept/Accept-Language/Accept-Encoding/Cache-Control）
- 使用模块级变量 `_original_get` / `_original_post` / `_original_Session` 保存原始引用，避免嵌套
- `instock/lib/http_client.py`：删除了冗余的 `patch_akshare()` 函数和自动调用
